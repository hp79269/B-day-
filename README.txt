HENI BIRTHDAY SURPRISE — MOBILE SETUP

1. Put your 3 real photos into the assets folder and name them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   (If your photos are .jpeg or .png, rename/convert them to .jpg or update the HTML filenames.)

2. Open index.html to test the website.
3. The site has 5 pages:
   Home → Message → Memories → Cake → Surprise
4. On the Cake page, tap the candles. After they are all off, confetti appears.
5. Upload the whole folder to GitHub Pages to get a shareable link.
6. You can then make a QR code for that link.

The Google Fonts import needs internet access. The website itself works without it, but the font falls back to normal fonts offline.
